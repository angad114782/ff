# 5. API Reference

Base: `/api`. JSON in/out. Auth is the `ff_session` HttpOnly cookie. Errors: `{ "error": "message" }` with 400 (validation), 401 (not signed in), 403 (wrong role / blocked origin), 404, 429 (rate limit), 502/503 (Business Central).

State-changing requests with an `Origin` header must be same-origin (or listed in `CLIENT_ORIGIN`).

## Auth
| Method & path | Body | Result |
|---|---|---|
| `POST /auth/login` | `{email, password}` | `{user}` + cookie. Rate-limited (10 / 15 min). Salesman logins are logged. |
| `POST /auth/logout` | — | 204 |
| `GET /auth/me` | — | `{user}` or `{user: null}` (always 200) |
| `POST /auth/forgot-password` | `{email}` | `{ok:true}` always; records a reset request for existing active salesmen |
| `PUT /auth/profile` | `{name, email, phone}` | `{user}` |
| `POST /auth/change-password` | `{current, next}` (next ≥ 8 chars) | `{ok:true}`; other sessions are signed out |

`user = { id, name, email, phone, role, branch, active }`

## Stock (any signed-in user)
### `GET /stock/search?q=&barcode=&page=1&pageSize=20`
Provide `q` (item no / name / SKU) or `barcode` (scanned text). A `q` starting with `http(s)://` is treated as a scan. `pageSize` ≤ 50.
```json
{ "items": [ { "code":"FF-0042458","name":"SAN MARINO-BEIGE","collection":"F CHENOVA","color":"GOLD",
               "uom":"MTR","available":114.52,"current":115.82,"vendorStock":150.5,"total":266.32,"status":"in_stock" } ],
  "page":1, "pageSize":20, "hasMore":false }
```
`vendorStock` is `null` when no vendor stock is available. `vendorStock` and `total` are left out when the search has a single match, because the client opens item detail directly.
### `GET /stock/item/:code`
Also returns `vendor` (`{status, stock, breakdown, po}`) and `totalStock` (`stock.current` + vendor stock).
```json
{ "item": {
  "code":"FF-0042458","name":"…","collection":"…","category":"UPHOLSTERY","family":"STOCK","color":"GOLD",
  "uom":"MTR","width":"140","mrp":797,"status":"in_stock","qrCode":"https://scan.fandf.in/D0SS",
  "stock": { "current":115.82,"reserved":1.3,"available":114.52,
             "locations":[{"location":"FFDH","qty":42.92},{"location":"FFMUM","qty":72.9}],
             "lots":[{"lotNo":"241336","location":"FFDH","qty":10.65}] },
  "po": { "qty":50,"transport":"SM COURIER","biltyNo":"…","biltyDate":null,
          "deliveryStatus":"UNDER PRODUCTION","deliveryDate":"11/10/26" },
  "vendor": { "status":"ok", "stock":150.5, "breakdown":[{"label":"Surat","qty":120.5},{"label":"Delhi","qty":30}], "po":{"qty":null,"expected":"2026-11-10"} },
  "admin": { "searchName":"…","purchasePrice":220,"vendorName":"TEE GEE FABRICS","vendorGroup":"CR-DOM-SUP",
             "contactNo":"…","externalItemId":"LM073-33" }   // admin only
} }
```
`404` if no exact `itemNo` match. `503` if BC isn't configured / credentials rejected (admins get a hint to check API Config), `502` for other BC failures.

## Media (signed in)
| | |
|---|---|
| `GET /media` | `{heroImages:[…], upcoming:[…]}`, each `{id, kind, name, type, url}` |
| `GET /media/file/:id` | the file (inline) |
| `POST /media/hero` · `POST /media/upcoming` (admin) | multipart `files` (≤10, ≤100 MB each). Hero: jpg/png/webp. Upcoming: also pdf, mp4, webm. → 201 `{media}` |
| `DELETE /media/:id` (admin) | 204 |

## Admin (admin only)
| | |
|---|---|
| `GET /admin/config/bc` | `{tenantId, environment, company, clientId, hasClientSecret, odataRoot}` — secret never returned |
| `PUT /admin/config/bc` | any of `tenantId, environment, company, clientId, clientSecret`; blank/missing secret keeps the stored one |
| `POST /admin/config/bc/test` | `{ok:true}` or 502 `{ok:false, error}` |
| `GET /admin/stats` | `{activeSalesmen, totalSalesmen, searchesToday, loginsToday, searchesWeek, notFoundWeek}` |
| `GET /admin/logs?type=&page=&pageSize=` | `{total, logs:[{id,type,name,email,query,found,timestamp}]}` newest first |
| `GET /admin/salesmen` | `{salesmen}` |
| `POST /admin/salesmen` | `{name,email,phone,branch,password}` → 201 |
| `PUT /admin/salesmen/:id` | `{name,email,phone,branch}` |
| `PATCH /admin/salesmen/:id/active` | `{active: boolean}` (drops live sessions) |
| `POST /admin/salesmen/:id/reset-password` | `{password}` |

| `GET /admin/vendors` · `POST /admin/vendors` · `PUT /admin/vendors/:id` · `DELETE /admin/vendors/:id` | vendor `{name, method, url, body, authType, authName, authSecret, mapping:{match,total,list,label,qty,poQty,poExpected}}`; secret is write-only (`hasSecret`) |
| `PATCH /admin/vendors/:id/active` | `{active: boolean}` |
| `POST /admin/vendors/test` | form fields + `externalItemId` → `{ok, paths:[{path,kind,sample,numeric}], preview:{stock,breakdown,po,matched?}}` or `{ok:false, error}` |

## Other
`GET /health` → `{ok:true}` (no auth). Unknown `/api/*` → 404 JSON.
