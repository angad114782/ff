# 12. MCP Connection

**The application does not use MCP (Model Context Protocol).** Business Central is reached directly over HTTPS/OData with OAuth2 client credentials (see doc 13); there is no MCP server in this repo and no MCP client in the app.

## Where MCP could apply (developer tooling only)
- Using an AI coding assistant on this repo: it reads `docs/6. AGENTS.md` for the rules. MCP servers configured in your assistant (e.g. API-testing or design tools) are personal tooling and are **not** part of the project or its deployment.
- If you later want an assistant to query stock, build a **separate** MCP server that calls this API (`/api/stock/*`) with a dedicated read-only account — never give an MCP server the BC client secret or the `APP_ENCRYPTION_KEY`.

## If you add MCP later
1. Keep it out of `server/src` request paths unless required; run it as its own process.
2. Authenticate it as a normal (salesman-role) user so role filtering still applies.
3. Don't expose admin routes or credentials through it.
4. Document the server, its tools and its credentials here.
