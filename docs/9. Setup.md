# 9. Setup

## Prerequisites
Node **24+** (project developed on 26; `node:sqlite` is required), npm 10+. HTTPS for anything beyond localhost (camera scanning and Secure cookies need it).

## Install
```sh
git clone <repo> && cd ff
npm install            # installs client + server workspaces
```

## Configure (development)
```sh
cp server/.env.example server/.env
```
Set at least:
```
PORT=4000
ADMIN_NAME=Your Name
ADMIN_EMAIL=admin@fandf.in
ADMIN_PASSWORD=<something long>
```
In development `JWT_SECRET` and `APP_ENCRYPTION_KEY` are generated into `server/data/dev-secrets.json` on first start. Remove `NODE_ENV=production` from the copied file for local work.

## Run
Two terminals:
```sh
npm run dev:server     # API  → http://localhost:4000  (restarts on change)
npm run dev:client     # UI   → http://localhost:5173  (proxies /api to :4000)
```
Open http://localhost:5173, sign in with the admin you set, then **API Config → Primary API** and enter the Business Central values:

| Field | Where it comes from |
|---|---|
| Tenant ID | Azure/Entra tenant GUID (appears in the OData URL) |
| Environment | BC environment name, e.g. `PRODUCTION` |
| Company | `F&F India Pvt. Limited.` |
| Client ID / Secret | App registration allowed to call BC (client-credentials), with BC API permission and the app registered in BC |

Press **Save Business Central**, then **Test Connection**.

## Test & build
```sh
npm test                # server tests
npm run lint:client
npm run build:client    # → client/dist
```

## Production
Required env (the server refuses to start without them):
```
NODE_ENV=production
JWT_SECRET=<openssl rand -base64 48>
APP_ENCRYPTION_KEY=<openssl rand -base64 32>
ADMIN_EMAIL=…  ADMIN_PASSWORD=…
TRUST_PROXY=1            # behind nginx/Caddy/LB
DATA_DIR=/data           # persistent volume
```
```sh
docker build -t ff-stock .
docker run -d -p 4000:4000 -v ff-data:/data --env-file server/.env ff-stock
```
Terminate TLS in front and proxy to :4000. Back up the `/data` volume and keep `APP_ENCRYPTION_KEY` safe (without it the stored BC secret can't be decrypted — re-enter it in API Config).

Without Docker: `npm run build:client && NODE_ENV=production node --env-file=server/.env server/src/index.js` (server serves `client/dist`).

## Reset
Stop the server and delete `server/data/app.db*` to start fresh (the admin is recreated from env).
