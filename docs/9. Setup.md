# 9. Setup

## Prerequisites
Node **24+** (project developed on 26) and a MongoDB database (Atlas or local `mongod`), npm 10+. HTTPS for anything beyond localhost (camera scanning and Secure cookies need it).

## Install
```sh
git clone <repo> && cd ff
npm install            # installs client + server workspaces
```

## Configure (development)
```sh
cp server/.env.example server/.env
```
Set at least:
```
PORT=4000
ADMIN_NAME=Your Name
MONGODB_URI=mongodb://127.0.0.1:27017/ff_stock
ADMIN_PASSWORD=<something long>
```
Secrets are generated into the database on first start.

## Run
Two terminals:
```sh
npm run dev:server     # API  → http://localhost:4000  (restarts on change)
npm run dev:client     # UI   → http://localhost:5173  (proxies /api to :4000)
```
Open http://localhost:5173, sign in with the admin you set, then **API Config → Primary API** and enter the Business Central values:

| Field | Where it comes from |
|---|---|
| Tenant ID | Azure/Entra tenant GUID (appears in the OData URL) |
| Environment | BC environment name, e.g. `PRODUCTION` |
| Company | `F&F India Pvt. Limited.` |
| Client ID / Secret | App registration allowed to call BC (client-credentials), with BC API permission and the app registered in BC |

Press **Save Business Central**, then **Test Connection**.

## Test & build
```sh
npm test                # server tests
npm run lint:client
npm run build:client    # → client/dist
```

## Production
Only one setting is required:
```
MONGODB_URI=mongodb+srv://USER:PASSWORD@cluster/ff_stock
```
Secrets, uploaded media, Business Central and vendor settings are all stored in that database. Open the site: the first visit shows a one-time "create admin" screen.
```sh
docker build -t ff-stock .
docker run -d -p 4000:4000 -e MONGODB_URI='…' ff-stock
```
Terminate TLS in front and proxy to :4000 (`TRUST_PROXY` defaults to 1 in production). Back up the database. Optionally set `JWT_SECRET` / `APP_ENCRYPTION_KEY` to keep those secrets outside the database.

Without Docker: `npm run build:client && NODE_ENV=production node --env-file=server/.env server/src/index.js` (server serves `client/dist`).

## Reset
Drop the database (or its collections). The next visit shows the create-admin screen again.
