# 6. AGENTS.md — guide for AI coding agents

Read this before changing the repo.

## Layout & commands
- `client/` React 19 + Vite + Tailwind. `server/` Express 5 (ESM, Node 24+). Docs in `docs/`.
- Dev: `npm run dev:server` (:4000) **and** `npm run dev:client` (:5173; proxies `/api`). Both must run — a 502 on `/api/*` means the server isn't up.
- Test: `npm test` (server, `node:test`). Client: `npm run lint:client`, `npm run build:client`.
- Dev admin is created on the first-visit setup screen (or via `ADMIN_EMAIL`/`ADMIN_PASSWORD` in `server/.env`); `MONGODB_URI` is required. Never commit `.env` or `server/data/`.

## Rules that are easy to break
1. **Secrets never reach the browser.** BC secret is write-only (`hasClientSecret` only). Don't add endpoints that return it; don't log it.
2. **Role filtering is server-side.** Salesman responses must not contain purchase price, vendor name/group/contact, external item id. Change `stockMapper.mapItem`, and extend `test/api.test.js` ("salesman never receives cost/vendor data").
3. **BC response is double-encoded:** `{ "value": "<JSON string>" }` whose parsed content is `{ "value": [ … ] }`. Always go through `unwrap()` in `bcApiService.js`.
4. **Express 5:** no regex in route params (`/:kind(a|b)` throws). Validate inside the handler/middleware. Async handlers may throw — errors reach the error middleware.
5. **MongoDB:** collections exported from `server/src/db.js`; numeric `_id` via `nextId()`; handlers are `async` (Express 5 forwards rejections); always validate input as strings before using it in a query (no NoSQL operator injection).
6. **Vite proxy must keep `changeOrigin: false`.** The CSRF check compares `Origin` to `Host`.
7. **Sessions:** after changing a user's password/active state, bump `token_version` so old cookies die.
8. **Validate input** with `lib/validate.js`; values that go into BC URLs (`tenantId`, `environment`) are restricted to `[A-Za-z0-9._-]`.
9. **Uploads:** extension comes from the allowlisted MIME map, never the filename.

## Conventions
- Match surrounding style: client uses small function components, Tailwind with brand tokens (doc 2), the `components/ui` primitives, `api` helper (`client/src/api.js`) and `useFetch` hook. No new colours/fonts.
- Comments explain *why*, not what. Keep them sparse.
- Server errors: throw `HttpError` helpers from `lib/errors.js`.
- Prefer a test with any behaviour change on the server; BC is mocked by stubbing `globalThis.fetch` (see `test/api.test.js`).
