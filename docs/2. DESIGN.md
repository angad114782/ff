# 2. Design System

Brand: F&F — "Designed for a life well lived". Warm, earthy, uncluttered; never bright blue/purple/neon. Tokens live in the `@theme` block of `client/src/index.css` (Tailwind v4); use the tokens, not raw hex.

## Colour
| Token | Hex | Use |
|---|---|---|
| `terracotta` | `#B25E44` | Primary buttons, active nav, key CTAs |
| `terracotta-deep` | `#8D381E` | Errors, out-of-stock, destructive |
| `sand` | `#F2E5D6` | Warm tint, hover, card inner backgrounds |
| `sage-soft` | `#AEAC90` | Secondary borders/buttons |
| `sage-grey` | `#C9C6B3` | Dividers, disabled |
| `linen` | `#FCFDF5` | App background (never pure white) |
| `green-livedin` | `#525937` | In stock / success |
| `ink` | `#2B2620` (not in the brand palette; neutral for body copy) | Body text |

Badges: success = `green-livedin` at 10% bg + text; error = `terracotta-deep` at 10% bg + text.

## Typography
- **Spline Sans** (400/500/600) for everything. Scale: `text-xs` meta, `text-sm` body/labels/cells, `text-lg` card titles, `text-xl/2xl` page titles.
- **Adventures Unlimited** (`font-display`) only for large hero text (login "Welcome back"), never below ~24px. Fall back to Spline Sans italic if unlicensed.

## Spacing, shape
4px Tailwind scale. Cards `p-4`–`p-6`; page padding `px-4 py-6`, `md:px-8 md:py-8`. Radius: inputs `rounded-md`, buttons/cards `rounded-lg`, modals `rounded-xl`. `rounded-full` only for avatars/dots/pills. Shadows subtle (`shadow-sm`; `shadow-md` only for modals/dropdowns).

## Motifs
- **The Arch** — arch-shaped logo block on Login (`rounded-t-full`). Not in dense data screens.
- **The Line** — thin terracotta divider.

## Components (`client/src/components/ui`)
`Button` (primary/secondary), `Input` (label + error), `Card` (title/action), `Badge` (success/error/neutral), `Table`, `TableSkeleton`, `Skeleton`, `Modal`, `Toggle`, `Pagination`. Build screens from these; add new primitives here rather than inline.

## Screens
Login · Admin: Dashboard, Dashboard Content, API Config, Salesmen, Stock Check, Item Detail, Logs, Profile · Salesman: Dashboard, Item Search, Item Detail.

## Accessibility & mobile
Keep text/background at WCAG AA (check terracotta text on sand). Inputs have labels; icon buttons have `aria-label`. Layouts use a mobile drawer nav under `md`. Scanner needs HTTPS or localhost for camera access.
