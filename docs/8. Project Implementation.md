## Removed
The old mock data layer (`client/src/mock/data.js`), `localStorage` persistence of users/logs/media, and the **Stock Sync** page (stock is live from BC, nothing to sync).

## Not built / known gaps
1. **Vendors** — generic, admin-configured connector is built (Admin → Vendors). No vendors are connected yet; Total shows our stock only until one is added and tested against the real vendor API.
2. **Vendors returning all items** — works via the External Item ID row, but downloads the full list per item, with a 1 MB cap. May need a cache and a higher cap once a real vendor needs it.
3. **Email** — no SMTP; password reset is admin-set.
4. **Shareable links / FTP publishing** — in the original scope, not implemented.
5. **DB migrations** — schema created idempotently only.
6. **Browser/E2E tests** — none; UI was verified manually in dev only partially.
7. **Real BC verification** — all BC behaviour was tested against a mock built from a sample response; first run against live BC should be watched (doc 15).
8. **Location names** — BC codes (`FFDH`, `FFMUM`) are displayed raw.

3. Remove or implement the unsaved API Config sections.
4. Add E2E smoke tests (Playwright) for login → search → detail.
5. Build and run the Docker image on the target host behind HTTPS.
