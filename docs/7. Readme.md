# 7. Readme

**F&F Stock Checker** — a mobile-first PWA that lets F&F salesmen check live stock from Microsoft Business Central by scanning a barcode or typing an item no, name or SKU. Admins manage users, the BC connection, content and activity.

- **Stack:** React 19, Vite, Tailwind, React Router · Node 24+, Express 5, MongoDB.
- **Quick start:** see [9. Setup](./9.%20Setup.md) and the root `README.md`.
