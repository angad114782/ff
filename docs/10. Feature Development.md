# 10. Feature Development

## Workflow
1. Branch from `main`.
2. Server first: route + validation + test. Then client screen.
3. `npm test`, `npm run lint:client`, `npm run build:client` before pushing.
4. Update the relevant doc (API → doc 5, schema → doc 4, behaviour/gaps → doc 8).

## Adding an API endpoint
1. Pick the router in `server/src/routes/` (admin-only → `admin.js`/`salesmen.js`; everyone signed in → `stock.js`/`media.js`).
2. Validate with `lib/validate.js`; throw `HttpError` helpers (`badRequest`, `notFound`, …).
3. Keep responses explicit — map DB rows (`publicUser`-style); never return raw rows with hashes.
4. Add a test in `server/test/api.test.js` (check 401 anonymous, 403 wrong role, happy path).

## Adding a client screen
1. Page in `client/src/pages/…`; register the route in `App.jsx` under the right `RequireRole`; add a nav link in the layout.
2. Data: `useFetch('/api/…')` for reads; `api.post/put/patch/del` for writes, surface `err.message`.
3. Compose from `components/ui`; use brand tokens only (doc 2). Show loading skeletons and error text.

## Showing another Business Central field
1. Confirm it's in the BC row (see doc 13 field map).
2. Add it in `stockMapper.js` (`mapSummary` for list, `mapItem` for detail). If it's cost/vendor related, put it under `admin`.
3. Extend the mapper test, then render it in `ItemDetail.jsx`.

## Connecting a new vendor
No code needed: Admin → Vendors → Add Vendor (name exactly as in the primary API, URL, login, Test, drag each response field opposite what it means). Only change `vendorConnector.js` if a vendor needs something the form can't express (e.g. non-JSON responses, multi-step login) — extend `callVendor` / `normalize` and add a test.

## Changing the schema
Edit `server/src/db.js`. New tables: `CREATE TABLE IF NOT EXISTS`. Altering existing tables needs a guarded `ALTER` (check `PRAGMA table_info`) — existing deployments won't re-run `CREATE`.

## Definition of done
Tests pass, no new lint errors, no secrets in logs/responses, salesman data exposure re-checked, docs updated.
