# 4. Database

MongoDB (any 6+; Atlas works). Connection string in `MONGODB_URI`; database name taken from it (default `ff_stock`). Collections and indexes are created at startup in `server/src/db.js`. Documents use a **numeric `_id`** from the `counters` collection, so the API still returns ids like `1, 2, 3`.

| Collection | Fields |
|---|---|
| `users` | `_id, name, email (unique, lowercase), phone, role ('admin'\|'salesman'), branch, active, password_hash (scrypt), token_version, created_at` |
| `logs` | `_id, type ('login'\|'search'\|'reset_request'\|'problem'), user_id, name, email, query, found, detail, created_at` |
| `vendors` | `_id, name (unique, case-insensitive), method, url, body, auth_type, auth_name, auth_secret (encrypted), mapping {…}, resolve {url,match,id}\|null, active, created_at` |
| `media` | `_id, kind ('hero'\|'upcoming'), name, type, mime, file_id, created_at` — bytes are in GridFS (`media_files.*`) |
| `settings` | `_id` = key: `bc` (Business Central connection, secret encrypted), `secrets` (JWT + encryption keys, generated on first start), `first_admin_lock` |
| `counters` | `_id` = collection name, `seq` |

## Operations
- **Backup:** `mongodump` / Atlas backups. The `secrets` document is in it; restore both together.
- **Import from the old SQLite version:** `MONGODB_URI=… node server/scripts/migrate-sqlite.js server/data/app.db server/data/uploads` (safe to re-run).
- **Reset dev data:** drop the database; the next visit shows the create-admin screen.
- **Retention:** `logs` grows unbounded; add a TTL index or periodic purge if volume warrants.
