# 4. Database

SQLite file `app.db` in `DATA_DIR` (default `server/data/`), WAL mode, foreign keys on. Schema is created idempotently at startup in `server/src/db.js` (`CREATE TABLE IF NOT EXISTS`). There is no migration tool yet: for a change, add `ALTER TABLE` guarded by a check, or introduce a `schema_version` table first.

## `users`
| Column | Type | Notes |
|---|---|---|
| id | INTEGER PK | |
| name | TEXT | |
| email | TEXT UNIQUE NOCASE | login id, stored lowercase |
| phone | TEXT | |
| role | TEXT | `admin` \| `salesman` |
| branch | TEXT | salesmen |
| active | INTEGER | 1/0; inactive cannot log in |
| password_hash | TEXT | `scrypt$salt$hash` |
| token_version | INTEGER | bumped on password change/reset/deactivate; invalidates JWTs |
| created_at | TEXT | ISO UTC |

First admin is created from `ADMIN_*` env when no admin exists.

## `logs`
`id, type ('login'|'search'|'reset_request'), user_id → users (SET NULL), name, email, query, found (0/1/NULL), created_at`. Index on `created_at DESC`. Only **salesman** logins/searches are written (admin lookups are not logged), plus reset requests from the forgot-password form. Denormalised `name/email` keeps history readable after a user changes or is removed.

## `settings`
`key TEXT PK, value TEXT (JSON)`. Currently one key, `bc`: `{ tenantId, environment, company, clientId, clientSecret }` where `clientSecret` is `enc:v1:<iv>:<tag>:<ciphertext>` (AES-256-GCM, key = `APP_ENCRYPTION_KEY`).

## `vendors`
`id, name (UNIQUE, NOCASE), method (GET|POST), url, body, auth_type (none|bearer|header|query|basic), auth_name, auth_secret (encrypted), mapping (JSON), active, created_at`. `name` is matched to the primary API's vendor name. `mapping` holds `{match,total,list,label,qty,poQty,poExpected}`; `list` may be `$` when the response itself is the list.

## `media`
`id, kind ('hero'|'upcoming'), name, type ('image'|'video'|'pdf'), mime, file, created_at`. `file` is a random hex name inside `DATA_DIR/uploads/`; the extension comes from the validated MIME type, never from the client filename.

## Not stored
Stock, prices, vendors, POs — read live from Business Central.

## Operations
- **Backup:** copy `DATA_DIR` (`app.db`, `app.db-wal`, `app.db-shm`, `uploads/`) — or use `sqlite3 app.db ".backup out.db"` while running.
- **Reset dev data:** stop the server, delete `server/data/app.db*`.
- **Retention:** `logs` grows unbounded; add a periodic purge if volume warrants.
