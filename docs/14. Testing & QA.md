# 14. Testing & QA

## Automated (server)
```sh
npm test        # node --test server/test/
```
`server/test/api.test.js` boots the real app on a random port with a temp DB and **stubs `globalThis.fetch`** to fake Microsoft sign-in and BC (including the double-encoded response). Covers:
- anonymous → 401; admin-only routes → 403 for salesmen
- login success/failure; case-insensitive email
- salesman lifecycle: create, duplicate email, login, deactivate kills the live session, reset password
- BC config: secret never returned, invalid tenant rejected, blank secret keeps stored one, test connection
- search: envelope parsing, company encoded in URL, scan → `qrCode`, salesman searches logged (found / not found)
- item detail: quantity maths, role filtering (no cost/vendor for salesman), no-vendor = "not configured", 404
- vendor API: response mapped to stock + breakdown, bad login, internal URLs blocked, secret write-only
- cross-origin write blocked
- media: salesman can't upload, admin can, file served, disallowed type rejected
- password change signs out other sessions

`server/test/mapper.test.js`: envelope `unwrap`, mapper tolerance of blank/missing fields and float noise, crypto round-trip + tamper detection.

## Not automated
Client components, routing, scanner, PWA install, Docker image, real BC. Add Playwright for login → search → detail → logout when the UI stabilises.

## Manual QA checklist
**Auth**
- [ ] Wrong password shows an error; 10+ rapid attempts get rate-limited
- [ ] Refresh keeps you signed in; logout returns to login
- [ ] Salesman visiting `/admin/*` is redirected to `/salesman`
- [ ] Deactivating a signed-in salesman logs them out on their next action

**Admin**
- [ ] API Config: save BC settings, secret field shows "saved", Test Connection OK / clear error
- [ ] Salesmen: add, edit, toggle active, reset password; duplicate email rejected
- [ ] Logs: filters, pagination; salesman search appears with Found / Not found
- [ ] Dashboard Content: upload hero image / PDF / video; appear on the salesman dashboard; delete works

**Search (against live BC)**
- [ ] By item no, by name (several results → list), by SKU
- [ ] Camera scan of an item QR opens that item; HTTPS required on phones
- [ ] Item detail numbers match BC: current = lots total, available = `QtyFree`
- [ ] Total Stock = current + vendor stock, in the list and on detail; vendor down → our stock only, with a message
- [ ] Vendors form: drag and tap place fields; a list response finds the row by External Item ID
- [ ] Salesman detail shows **no** purchase price / vendor; admin does
- [ ] BC down / wrong credentials → friendly message, no stack traces

**Mobile / PWA**
- [ ] Install to home screen; drawer nav works; no horizontal scroll on item detail
